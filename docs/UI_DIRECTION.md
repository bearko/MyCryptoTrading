# My Crypto Trading — UI／演出の設計書（アートバイブル）

この文書は、画面・動き・音・エフェクトを作るときの **唯一の基準** です。迷ったらここに戻る。
ルール（ゲームの仕組み）は `docs/GAME_DESIGN.md`、ここは「どう見せ、どう触らせ、どう鳴らすか」。

## 0. 一言で

**「GUM POP」— ドット絵 × 印刷物のようなポップ・グラフィック。**
インクの黒、紙の白、GUM の黄色。斜めに切った板、太い縁取り、ずらした影、網点。
画面のどこも止まらない。押したら必ず返ってくる。店は生きている。

目指す感想は「ブラウザのゲームで、ここまでやるのか」。

## 1. いまの画面の問題（作り直す理由）

| 摩擦 | 何が起きているか | 直しかた |
|---|---|---|
| 手応えがない | ボタンを押しても画面が静かに差し替わるだけ。売れても数字が変わるだけ | すべての操作に、80ms 以内の見た目＋音＋（対応端末で）振動 |
| 画面が死んでいる | 待っているあいだ何も動かない | 背景・客・ラベル・数字のどれかが常に動く |
| 階層がない | 茶色とクリーム色の中に、大事な数字も補足も同じ重さで並ぶ | 黒地に、GUM 黄色は「お金と決定」だけ。一番大事なものが一番大きく、一番明るい |
| 世界と UI が別物 | 木目の UI とドット絵が、たまたま同じ画面にあるだけ | UI を「印刷物・値札・スタンプ・レシート」として、店の持ちものにする |
| 山場がない | 開店も、売れた瞬間も、家賃も、同じ調子で過ぎる | 山場（開店・成約・閉店・遭遇・勝利・買い取り）に 500〜700ms の演出を置く |
| 画面の作り直し | 操作のたびに全体を作り直すので、動きが途切れる | DOM を差分で更新する（要素を生かしたまま変える） |

## 2. 色

黒地が基本。色は意味でだけ使う。

| トークン | 値 | 使いみち |
|---|---|---|
| `--ink` | `#0f0d16` | 地の色、縁取り、影 |
| `--ink-2` | `#1c1826` | パネルの地 |
| `--ink-3` | `#2d2740` | 仕切り、押せない部品 |
| `--paper` | `#fff8e7` | 紙（カード・吹き出し・レシート） |
| `--paper-2` | `#f1e6c8` | 紙の影の面 |
| `--gum` | `#ffd21f` | **お金と決定だけ**（GUM の数字、主ボタン、成約） |
| `--hot` | `#ff3b5c` | 警告・損・PHY系・敵のダメージ |
| `--cool` | `#2d8cff` | INT系・情報 |
| `--leaf` | `#2fd67b` | AGI系・得・回復 |
| `--violet` | `#8f5bff` | 夜・クエスト・デバフ |
| `--mute` | `#8d86a3` | 補足の文字 |

- 系統の色：PHY＝`--hot`、INT＝`--cool`、AGI＝`--leaf`、HP＝`--gum` 寄りの土色。
- **色だけに頼らない**：系統には形の印も付ける（PHY ▲・INT ◆・AGI ●）。損得は ＋／− と矢印でも示す。
- 昼の場面は暖色、夜は `--violet` に寄せた色調（場面全体に薄く重ねる）。
- UI は背景より必ず鮮やかに。背景は彩度と明度を落として、UI を前に出す。

## 3. 文字

| 役割 | 書体 | 例 |
|---|---|---|
| 見出し・叫び | Dela Gothic One | 「開店！」「SOLD」「地下 3 階」 |
| 数字・英字 | Anton（斜体ぎみに傾ける） | GUM、日数、ダメージ |
| 本文 | Zen Kaku Gothic New（500／700／900） | 説明、ボタン |
| 世界の声 | DotGothic16 | 客のせりふ、品の名前、ログ |

- 本文は 13px 以上、補足でも 11px を下回らない。数字は等幅（`tabular-nums`）。
- 見出しは詰めて大きく。文字にも縁取りとずらした影を付けてよい。

## 4. 形と質感

- **斜めの板**：パネルやボタンは −6°〜−10° の平行四辺形（`clip-path` か `transform: skewX`）。中の文字は傾けない。
- **縁取りとずらした影**：3px の `--ink` の縁、ぼかさない影（`4px 4px 0 var(--ink)`）。押すと影が潰れて沈む。
- **網点と縞**：地には網点（radial-gradient の繰り返し）か斜め縞を薄く敷き、ゆっくり流す。
- **紙もの**：値札（上に穴）、テープ留めのラベル、スタンプ（少し回転・かすれ）、レシート（下がギザギザ）。
- **ドット絵はくっきり**：`image-rendering: pixelated`、整数倍に近い大きさ。白か黒の輪郭（drop-shadow を 4 方向）で UI から浮かせる。
- **重なり**：UI と場面を分けない。大きな見出しの手前に客が立つ、客の後ろを帯が横切る、のように奥行きを作る。

## 5. 動き

| 種類 | 時間 | イージング |
|---|---|---|
| 押した反応 | 60〜100ms | `ease-out`（縮む → 戻る） |
| 出る | 180〜320ms | `cubic-bezier(.2, 1.4, .3, 1)`（少し行きすぎて戻る） |
| 消える | 120〜180ms | `ease-in` |
| 山場 | 500〜700ms | 溜め（ヒットストップ 60〜120ms）→ 一気に |
| 待機のゆらぎ | 2〜6s のループ | `ease-in-out` |

- リストは 30ms ずつずらして出す。
- 動かすのは `transform` と `opacity` だけ（レイアウトを揺らさない）。
- **止まっている画面を作らない**：客は 2 コマの呼吸、網点は流れ、黄色い部品は脈を打ち、帯の文字は流れる。
- `prefers-reduced-motion` と設定「演出をひかえる」で、移動・揺れ・点滅をやめ、フェードだけにする。情報は失わない。

## 6. 手応えの対応表

すべての操作は「見た目・音・振動」の 3 つで返す。`audio.sfx(名前)`、`fx.*`、`haptic(強さ)` を使う。

| できごと | 見た目 | 音（`SfxName`） | 振動 |
|---|---|---|---|
| ボタンを押す | 縮んで戻る、影が潰れる | `tap` | 軽 |
| 決定（主ボタン） | 黄色が一瞬白く光る | `confirm` | 軽 |
| 取り消し・閉じる | 板が引っこむ | `cancel` | — |
| 窓が開く／閉じる | 斜めに滑りこむ／引っこむ | `open`／`close` | — |
| 品をつまむ | 浮いて影が伸びる、傾く | `pick` | 軽 |
| 品を置く（成功） | 置いた所から埃、マスが光る | `drop` | 軽 |
| 品を置けない | 赤く震えて戻る | `dropBad` | 2 回 |
| 回転 | くるっと 90° | `rotate` | — |
| 開店 | シャッターが巻き上がる、光が差す、「OPEN」の帯 | `shutterUp` | 中 |
| 客が来る | 名札が斬りこむ、足もとに埃 | `step`（歩数ぶん） | — |
| せりふ | 場面の左上に出る（客の顔にかからない）。1 文字ずつ、吹き出しが文の長さに合わせて伸びる。言い終えたら消える。来店のときは、消えてから伝票が開く | `voice`（気質で高さが変わる） | — |
| 買い取り | 品が棚へ飛ぶ、GUM が減る数字が流れる | `buy` | 軽 |
| 売れた | 「SOLD」のスタンプ、コインが飛んで所持金へ吸いこまれ、数字が回る | `coin`（額が大きいと `coinBig`） | 中 |
| 値切り成功 | 「DEAL」のスタンプ、言い値が打ち消されて新しい値に | `haggleOk` | 中 |
| 断られた | 客が首を振る、我慢の玉が 1 つ割れる | `refuse` | 軽 |
| 怒って帰る | 画面が揺れる、怒りの印 | `angry` | 強 |
| ベル | ベルが揺れる、音の輪が広がる | `bell` | 軽 |
| 閉店 | シャッターが落ちて埃、「CLOSED」 | `shutterDown` | 強 |
| 締め | レシートが 1 行ずつ印字される、合計にスタンプ | `receipt`（行ごと）、`stamp` | — |
| 家賃を払う | GUM が吸い取られる | `rent` | 中 |
| 注文を達成 | 「注文達成」のスタンプ、注文の札からコインが所持金へ飛ぶ、札が黄色い枠に変わる | `haggleOk` | 強 |
| COMBO が伸びる | COMBO の札が弾む、「おまけ +n」が浮く。伸びるほど音が高くなる | `coin`（高さが上がる） | — |
| 特別な客が来た | 黄色い帯が横切って名前を告げる、名札に印 | `event` | 中 |
| 商才を選ぶ | 選んだ札が光り、名前のスタンプと星 | `equip` | 軽 |
| ドア | 開いて夜の光がもれる | `door` | — |
| 装備 | 枠にはまって光る、ステータスが跳ね上がる | `equip` | 軽 |
| 階を進む | 斜めの帯が横切って場面が変わる | `stairs` | — |
| 品を拾う | 宝がはじけて出る | `found` | 軽 |
| 敵と遭遇 | 「！」、警告の縞、敵が斬りこむ | `encounter` | 強 |
| 攻撃が当たる | ヒットストップ、白く光る、数字が跳ねる、揺れ | `hit`／`hitBig` | 中 |

## 7. 画面ごとの方針

- **タイトル**：題字が 1 文字ずつ落ちてくる。背景をヒーローたちが歩いて横切る。網点が流れる。
- **上の帯（HUD）**：左に日付の札、中央に所持 GUM（一番大きい数字。増減は数字が回り、差分が飛ぶ）、右に評判。家賃は「あと n 日」のゲージで、近づくと赤く脈を打つ。
- **朝**：号外のような紙が叩きつけられ、本日のイベントが見出しになる。「開店」で大きな帯が横切る。
- **客**：カウンターの奥に大きく立ち、呼吸する。機嫌で跳ねる・震える。名札と「売りたい／買いたい」の札。
- **客のウィンドウ**：伝票（紙）として作る。上の帯をつかんで動かせる。合計は一番大きく。
- **カウンター**：奥と手前で色を変え、置ける所は点線が流れる。置いた品は値札つき。ベルは真鍮色で、鳴らせるときは揺れる。
- **棚**：黒い板に網点。品は系統の色の板に載る。つまむと浮く。置ける／置けないを緑／赤で示す。
- **夜**：シャッターに落書きのような網点、ドアからネオンの光。締めはレシート。
- **夜のショップ**：品は値札つきのカードが並ぶ。買うとウォレットへ飛ぶ。
- **装備**：ウォーリアーが中央で呼吸。枠は場所ごとに印がある。装備するとステータスの数字が跳ねて増える。
- **クエスト**：別の世界に入った、と分かる色（紫と黒）。階の表示は大きな数字。敵は大きく、名前の帯つき。スキルは札として並び、使うと技名の帯が横切る。HP は減った分が遅れて追いかける。
- **設定**（「?」から）：BGM・SE の音量、演出をひかえる、振動、文字を大きく。

## 8. だれでも遊べるように

- 色覚の違い：系統は色＋形の印、損得は色＋記号。赤と緑だけで区別させない。
- 文字：設定「文字を大きく」で全体を 1.15 倍。重要な数字は 16px 以上。
- 動き：設定と OS の指定で演出をひかえる。点滅は 1 秒に 3 回を超えない。
- 押しやすさ：押せる部品は 44px 以上。下半分に主な操作。
- 音がなくても遊べる（音だけで伝える情報を作らない）。最初の操作まで音は鳴らさない。

## 9. 実装の約束

- **CSS の変数**は `src/styles/tokens.css` にあるものを使う。色を直接書かない。
- **音**は `src/ui/audio.ts`、**エフェクト**は `src/ui/fx.ts`。画面のコードはこの 2 つの API だけを呼ぶ。
- **画面の更新**は差分で行う（`morphdom`）。要素に `id` か `data-key` を付けて、生かしたまま変える。出るときの動きは「要素が新しく入ったとき」に 1 回だけ流れる。
- ルール（`src/game/`）は見た目を知らない。演出に必要な「何が起きたか」は、ルール側が出来事の一覧として返す。
- 60fps を保つ。粒子は同時に 300 個まで。古いスマホでは自動で減らす。
