# My Crypto Trading ゲーム設計書

My Crypto Heroes（以下 MCH）の世界で交易店を営む、スマホ（縦持ち）向けの店舗経営・取引ゲーム。
1 プレイは 30〜60 分、片手で遊べることを目標にする。

## 1. コンセプト

**「安く買って、高く売る。家賃に追われる前に、店を自分のものに。」**

- 借り物の店で商いを始め、7 日ごとに上がっていく家賃を払いながら GUM を貯め、店の権利書を買い取ればクリア。
- 面白さの芯は、カウンター越しの一対一の駆け引き。押せば儲かるが、押しすぎると客は怒って帰る。
- 店番はクリスくん。客は MCH のヒーロー、商品はエクステンション。

## 2. MCH 素材の割り当て

| ゲーム内の役 | 素材 | 使いかた |
|---|---|---|
| 商品 | エクステンション 956 種（図鑑に載るもの。レプリカは除く） | レアリティが相場を決める。得意なステータス（PHY / INT / AGI）が「種別」になる |
| 客 | ヒーロー 209 体（図鑑に載るもの） | レアリティが高いヒーローほど、いい品を持ち込み、予算も多い |
| 店番 | クリスくん（立ち絵の差分） | 朝・締め・結末で表情を変えて一言 |
| 通貨 | GUM | 所持金・値段のすべて |
| 背景 | バトル背景（街） | カウンターの向こうの景色 |

勢力（玄武・朱雀・青龍・黄竜・白虎）のデータはカタログに入れてあり、今後の「勢力ごとの評判」で使う。

## 3. 1 日の流れ

1. **朝の仕入れ**：卸売り商が 3 品を相場より少し安く（86〜96%）持ってくる。買うかどうかを決めて店を開ける。
2. **営業**：客が 1 人ずつカウンターに来る（1 日 5〜9 人。評判で増える）。客は 2 種類。
   - **売りに来た客**：品と言い値を出してくる。買う／値切る／色をつけて買う／見送る。
   - **買いに来た客**：欲しい物（種別・レアリティ以上・何でも）と予算を言う。棚から品を選び、値をつけて売る。
3. **締め**：その日の収支を見る。棚を広げる、権利書を買い取る、在庫を処分する。眠ると翌日へ。
   7 日目ごとの夜に家賃が引かれる。

## 4. ルール

数字はすべて `src/game/balance.ts` にある。ここに書くのは 0.1.0 時点の値。

### 4.1 相場

- 相場 ＝ レアリティの基準額（20 / 50 / 120 / 300 / 800）× 品ごとの固有の振れ（±15%。同じ品はいつも同じ）× 状態（傷あり 0.7・並品 1.0・美品 1.25）。
- 相場は画面にいつも出す。プレイヤーが考えるのは「この客から、いくらまで取れるか」。

### 4.2 客の気質と我慢

| 気質 | 割合 | 我慢 | 交渉の通りやすさ | 言い値（相場に対して） |
|---|---|---|---|---|
| 気さく | 30% | 3 | +12% | 58〜70% |
| ふつう | 45% | 2 | ±0 | 66〜78% |
| 頑固 | 25% | 1 | −15% | 74〜88% |

- 値切りや上乗せを断られるたびに我慢が 1 減る。0 になると怒って帰り、評判が 2 下がる。
- 頑固な客は一度断られたら終わり。気さくな客には強気に出られる。

### 4.3 買い取り（客 → 店）

| 行動 | 支払う額 | 成功率（基準） | 評判 |
|---|---|---|---|
| 買う | 言い値 | — | ±0 |
| 値切る 15% | 言い値の 85% | 80% | ±0 |
| 値切る 30% | 70% | 50% | ±0 |
| 値切る 45% | 55% | 20% | −1 |
| 色をつけて買う | 言い値の 115% | — | +3 |
| 見送る | — | — | ±0 |

- 値切りが通るのは 1 人につき 1 回。通ったあとの値でもう一度値切ることはできない。
- 成功率には、気質の補正と評判の補正（(評判 − 50) ÷ 250）が足される。画面には補正後の数字を出す。
- 「色をつけて買う」は、利益を削って評判を買う手。

### 4.4 販売（店 → 客）

- 定価 ＝ 相場 × 1.1。
- 定価 / +15% / +30% / +50% から選ぶ。成功率は 100% / 80% / 50% / 22%（気質と評判の補正つき）。
- 客の予算を超える値は出せない。希望に合わない品は受け取らない。
- 定価で売ると評判 +1。+50% で売ると −1。

### 4.5 評判（★ 0〜100、はじめは 30）

- 1 日の客の数 ＝ 5 ＋ 評判 ÷ 25（切り捨て）。
- 評判が高いほど、持ち込まれる品のレアリティが上がり、交渉も通りやすい。
- 強気の商いは今日の儲け、良心的な商いは明日の客。この釣り合いがゲームの軸。

### 4.6 棚（在庫の枠）

- はじめは 8 枠。2 枠ずつ 4 回まで広げられる（200 / 400 / 700 / 1,100 GUM）。
- 棚がいっぱいだと買い取れない。売りに来る客の割合も、棚の空きに合わせて変わる（空なら売り客が多く、満杯なら買い客が多い）。
- いらない品は、いつでも卸売り商に相場の半値で処分できる。

### 4.7 家賃と権利書

- 家賃は 7 日ごと。はじめは 300 GUM、払うたびに 15% 上がる。
- 払えないときは一度だけ猶予が使える（払えなかった分は次の家賃に上乗せ）。二度目は店を失う（ゲームオーバー）。
- 権利書は 5,000 GUM。締めの画面で買い取るとクリア。そのあとは家賃なしで続けられる。
- 記録は「何日目で買い取ったか」。

## 5. 画面（縦持ち）

```
┌──────────────────────────┐
│ 3日目（水）   GUM 412   ★ 34 │  ← 状況（家賃まであと何日・いくら）
│ 家賃 あと4日 300            │
├──────────────────────────┤
│        （吹き出し）          │
│ クリスくん     ヒーロー       │  ← カウンターの場面（背景は街）
│          名前 気質 我慢●●○   │
├──────────────────────────┤
│ 品のカード（絵・相場・状態）  │
│ [ 買う ]      [ 値切る ]     │  ← 取引のパネル（親指の届く下半分）
│ [ 色をつける ] [ 見送る ]     │
├──────────────────────────┤
│ [ 在庫 5/8 ]   [ 遊びかた ]  │
└──────────────────────────┘
```

- 操作はタップだけ。大事なボタンは画面の下半分に置く。
- 成功率・予算・相場は隠さずに出す。運に任せる部分を、読める賭けにする。
- 進行は操作のたびに端末へ保存する（`localStorage`）。

## 6. バランスの計測

`npm run sim` で、2 種類のボットに 300 回ずつ遊ばせる（`tests/economy-sim.test.ts`）。

| 遊びかた | クリアした割合 | 店を失った割合 | クリアまでの日数（早い 10%・中央・遅い 10%） |
|---|---|---|---|
| 値切らず、定価で売る | 84% | 16% | 48・65・84 |
| 相手を見て値切り、上乗せする | 100% | 0% | 34・45・54 |

- 狙い：駆け引きを使えば 5〜8 週でクリアでき、使わなくても多くは生き残れるが、時間がかかる。
- テストはこの関係（駆け引きが得になる・定価でもおおむね生き残れる）が崩れると落ちる。

## 7. 今後の予定

0.1.0 は「取引・値切り・家賃」まで。次の候補を、効果の大きそうな順に並べる。

1. **目利き（偽物）**：持ち込まれる品にレプリカが混じる。絵の違いを見抜けば安く買い叩け、見逃して売ると評判が落ちる。レプリカの絵は素材にある。
2. **勢力ごとの評判**：5 勢力それぞれに評判を持ち、節目ごとに特典と不利益がつく。
3. **訳ありの品と見回り**：儲かるが、見回りで見つかると没収される品。
4. **夜の行動**：閉店後に探索へ出て品を拾う（翌日の客が減る）。
5. **加工**：安い品を組み合わせて価値を上げる。
6. **開始時の職と特性**：はじめの在庫と条件を変えて、遊ぶたびに違う展開にする。
7. **音**：BGM と効果音（素材にある）。
8. **ホーム画面への追加（PWA）と英語表示**。
